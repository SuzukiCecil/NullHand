# NULL-HAND（ヌルハンド）

2枚見せて、1枚で勝負。限られた手札を読み合う、CPUとの2人用心理戦じゃんけん。

- 手札は12枚（グー・チョキ・パー各2枚、ヌル6枚）。ヌルはすべてに負け、ヌル同士はあいこ。
- 毎ラウンド2枚を伏せて同時に表にし、そのうち1枚を同時に選んで勝負。場の4枚は除外。
- 先に3勝で勝ち。6ラウンドで決まらなければ勝ち数で判定（同じなら引き分け）。
- CPUは最後まで読み切った均衡戦略（やさしい／ふつう／つよい）。

```sh
npm install
npm run dev     # 開発サーバー
npm test        # ルールとCPUのテスト
npm run sim     # CPU同士の対戦（docs/balance.md）
npm run build
```

仕様は `要件定義書.md`。
